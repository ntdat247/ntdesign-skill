# ntdat-frontend-design

A unified, high-craft frontend engineering skill for AI coding agents (Claude Code, Cursor, Windsurf, Antigravity, GitHub Copilot, Codex).

## Core Architecture (5 Pillars)

1. Pre-code Design Thinking, intentional aesthetic direction, surface layering, and complete zero-placeholder execution.
2. Anti-AI visual discipline (no neon purple gradients or repetitive 3-card grids), asymmetrical hierarchy, and concise, zero-fluff copywriting.
3. Physics-based motion engineering, snappy custom `cubic-bezier` easing (`120ms-240ms`), origin-aware popovers, and tactile press feedback (`scale(0.98)`).
4. Semantic DOM, keyboard-first navigation (`:focus-visible`, `aria-label`), layout stability (`tabular-nums`, zero CLS), defensive truncation (`min-w-0`), and full state coverage (`empty`, `loading`, `error`).
5. Token architecture & semantic color discipline: HSL token pairs with light/dark parity, three-token status system (text/surface/border), strict brand ≠ status ≠ focus role separation, color budget (neutrals dominate; color only on violation), and dashboard density recipes (`references/tokens-template.css`, `references/ops-components.md`).

## Installation

```bash
npx skills add ntdat247/ntdesign-skill
```

## Update

```bash
npx skills update ntdat-frontend-design
```

- `-g, --global` — global (user-level) installs only · `-p, --project` — project installs only · `-y, --yes` — skip the scope prompt
- Alternative: re-run `npx skills add ntdat247/ntdesign-skill` — reinstall is idempotent and overwrites with the latest version
- Check what is installed (and where) with `npx skills ls`
