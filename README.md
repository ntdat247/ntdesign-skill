# ntdat-frontend-design

A unified, high-craft frontend engineering skill for AI coding agents (Claude Code, Cursor, Windsurf, Antigravity, GitHub Copilot, Codex).

## Core Architecture (4 Pillars)

1. Pre-code Design Thinking, intentional aesthetic direction, surface layering, and complete zero-placeholder execution.
2. Anti-AI visual discipline (no neon purple gradients or repetitive 3-card grids), asymmetrical hierarchy, and concise, zero-fluff copywriting.
3. Physics-based motion engineering, snappy custom `cubic-bezier` easing (`120ms-240ms`), origin-aware popovers, and tactile press feedback (`scale(0.98)`).
4. Semantic DOM, keyboard-first navigation (`:focus-visible`, `aria-label`), layout stability (`tabular-nums`, zero CLS), defensive truncation (`min-w-0`), and full state coverage (`empty`, `loading`, `error`).
